# SimplyReview - Literature Review made easy

## Setup

1. Create a python environment (venv) using the following command

```
python3 -m venv .venv
```

2. Source the python environment using the following command

```
source .venv/bin/activate
```

3. Install all requiremnts listed in requirements.txt using the following command

```
pip install -r requirements.txt
```

4. Install neo4j desktop, create a project.

5. Update .env file with relevant access keys

6. Run the application using the following command

```
streamlit run app.py
```
